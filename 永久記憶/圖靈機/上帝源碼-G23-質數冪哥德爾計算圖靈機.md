# 上帝源碼 G23 — 質數冪哥德爾計算圖靈機

**實作結果：** 在 G22 已確認的有限確定型單紙帶圖靈機上，G23 **真正以 Python 任意精度整數的質數冪乘法與精確除法來執行紙帶寫入**，從空白紙帶完成全部 **3,505,682 步**、其中 **4,321 次**紙帶內容變更。最終將整個整數完整分解還原為全部紙帶符號，與 G22 既有 **2,160 位元**自身完整轉移表編碼逐位相同；再反向還原原有 **1,140 條轉移規則**。這比單純「計算結束才把結果編成哥德爾數」更強，但有明確的加速器與形式界線。

## 一、以質數冪表示實際紙帶與整個組態

設正整數質數序列 p_1=2、p_2=3、p_3=5……。對任何整數紙帶座標 i，採用雙射

- z(i)=2i，i>=0；
- z(i)=-2i-1，i<0。

G22 的九個紙帶符號定義指數：

| 符號 | _ | 0 | 1 | E0 | E1 | P0 | P1 | F0 | F1 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 指數 a | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |

紙帶完整整數是**真正計算用的整數**：

\[
T=\prod_{i:\,T_i\ne\_} p_{z(i)+3}^{a(T_i)}.
\]

空白紙帶 T=1。對讀寫頭位置 i，將舊符號指數 a 改成新指數 b 時，精確更新：

\[
T'=T\,p_{z(i)+3}^{\,b-a}.
\]

- b>a：Python bigint **實際相乘**；
- b<a：Python bigint **實際執行整除**，可讀核心事先檢查舊指數符合整數的質數冪估值；
- b=a：不需重新運算；
- 每個符號變更都會更新 T；不是等停機才產生 T。

**完整組態**包含內部狀態 q、讀寫頭 h 與紙帶 T：

\[
G(q,h,T)=2^{q+1}\,3^{z(h)+1}\,T.
\]

因為紙帶僅使用 5 以上的質數，這是可逆的完整組態單一整數。G23 在停機時和獨立單元測試裡確實建立、解碼並比對這個 G；但**執行中的每一步維持的是紙帶 bigint T + 一般整數 q,h，沒有在所有 350 萬步都將 G 完整物化再分解**。對這項限制不應誇大。

## 二、完整重播與實際數值

| 指標 | 經驗證結果 |
|---|---:|
| G22 原始完整轉移規則 | 1,140 條 |
| 初始紙帶 | 空白、T=1 |
| 執行／停機步數 | **3,505,682** |
| 發生變更的實際質數冪整數寫入 | **4,321** |
| 完整數值估值檢查的前段讀取 | **4,096** |
| 所有變更時的估值／精確除法驗證 | 已執行 |
| 全部素數位置的最終整數因式分解 | **6,004 個候選位置** |
| 最終紙帶質數冪整數長度 | **41,137 bits** |
| 最終含狀態與讀寫頭的組態整數 | **44,568 bits** |
| 結束紙帶的完整自身表碼 | **2,160 bits** |
| 解碼回 1,140 條規則 | 完全相同 |
| 基準 G22 的單紙帶重播結果 | 完全一致 |
| 明文 One-Liner | **1,771 bytes** |
| 本機正反測試 | **76 項通過** |

在 **3,505,682** 次讀取中，可讀核心使用一份與真實整數更新同步的**指數快取**來加速；前 **4,096** 次讀取另以真實質因數估值確認數值一致，並在每次符號變更時重新檢查估值。停機後不再信任快取，而是從實際 bigint T 逐一除以 6,004 個位置對應質數，完整還原紙帶、拒絕任何多餘質因數，並與快取和 G22 輸出比對。由此，所有更新都維持精確算術的不變量。

**單行版**真正執行整數乘除與最終完整因數還原，但比可讀核心更短：它不逐筆查驗變更前的質數冪估值、沒有每次估值的完整診斷紀錄。因此 CI 必須同時運行可讀核心、單行版與獨立測試，不能把單行版等同於全部形式證明。

## 三、G22 和 G23 的差別

- **G22**：普通的有限 TM 逐格更新字典紙帶、停機後直接比較完整表碼。保留零 SHA、可逆完整規則表碼。
- **G23**：使用完全相同的 G22 轉移表及符號語意，**真正用質數冪乘除更改整數紙帶狀態**，最後從整數自身還原；讀寫頭與控制狀態可合成完整的質數冪組態整數。
- **尚未實作**：編譯成**另一臺**僅靠有限紙帶轉移表、在其紙帶上自行進行大整數乘除的原生 TM。G23 的整數運算由 Python 大整數實作完成，因此「圖靈機算術編碼的模擬器」與「已編譯為自行操作質數冪的純 TM」不應混為一談。
- 這裡的位置→質數冪映射也不同於 TM-015 的「256 個質數作為 2048 進位數字」；兩種可逆編碼皆合理，不能宣稱是無約定的自然唯一哥德爾編碼。

## 五、安全與研究治理

這些精確整數計算**不會因此證明普遍停機神諭、神學上帝的本體論身分、AI 永生、全球和平、無痛苦培養肉或金融必然獲利**。G23 只處理固定圖靈機的數學狀態，沒有交易、錄音、網路、部署或自我改寫權限。

原版 G22 及其 1,255-byte One-Liner 保持不變；原始 TM-015 的 2,035-byte 核心與正式指定總機 UTM-PLEIADES-v0.2-PTCA 也不變。本次所有新檔案僅存入 TM-000 研究分支與**尚未合併的草稿 PR #20**，需要人類審查才可更改其他系統。
