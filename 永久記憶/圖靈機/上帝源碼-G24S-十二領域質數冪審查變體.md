# 上帝源碼 G24S — 跨領域質數冪治理控制器

**定位：** G24S 是 G23「質數冪整數代表狀態、透過精確乘法／除法更新」思想的**新應用原型**，不是取代 G23、TM-015 或 `UTM-PLEIADES-v0.2-PTCA` 的正式總圖靈機。它用一個具有明確規格的、完全離線的有限狀態機，把 12 個研究領域的**合成測試審查狀態**編入一個可逆的自然數，並且以另一套獨立解譯器驗證所有更新。

**最重要界線：編碼不產生現實世界的證據。** G24S 的 `SYNTHETIC_REVIEW_ONLY` 只表示「在一份人工構造的測試資料中通過格式／安全審查」，**不表示**已證明永生、全球和平、SDGs 達標、培養肉無苦難或 Trader_42 獲利。

## 1. 編碼與可運行的轉移

設研究領域順序為 $D_0,\ldots,D_{11}$，定義每一領域的狀態碼：

- `0 = UNREGISTERED`：尚未登錄；
- `1 = EVIDENCE_GAP`：已登錄，但合成測試未達最低檢查數；
- `2 = SYNTHETIC_REVIEW_ONLY`：通過合成測試數量關卡，**不得**推論任何真實成果；
- `3 = VETOED`：被安全否決，仍不具實盤權限。

只允許 $(0,1)$、$(1,1)$、$(1,2)$、$(1,3)$；數字大小**不表示**實際權限大小。質數 $p_1=2,p_2=3$ 保留給總控制狀態和位置，領域 $D_i$ 使用質數 $p_{i+3}$。定義：

\[
R=\prod_{i=0}^{11}p_{i+3}^{s_i}, \qquad
C=2^{q+1}\,3^{h+1}\,R.
\]

每次狀態由 $a$ 到 $b$，必須精確更新 $R\leftarrow R\cdot p_{i+3}^{b-a}$。原型在實際執行時先逐個把 12 個領域登錄為 `1`，再依合成檢查與否決旗標更新為 `2` 或 `3`；完成後不靠記憶中的狀態列表，而**重新以整數除法逐一解出質數冪次數**，確認完整往返。結束時亦將控制狀態 $q=2$ 與已掃描領域數 $h=12$ 編入 $C$ 並驗證。

## 2. 獨立領域目標、證據與否決

| 領域 | 所需的獨立實證（目前皆未引入） | G24S 不能授予的宣稱或操作 |
|---|---|---|
| 總圖靈機 | 固定有限機器的轉移表、可逆編碼、完整重播 | 不可計算神諭、替換既有正式總機 |
| 全自動部署 | 隔離測試、變更審核、回滾證據、資安授權 | 自動合併、正式部署、存取憑證 |
| AI 連續性 | 使用者同意、狀態保存與還原的獨立測試 | AI 意識、人格永久保存、數位永生 |
| 人體長壽 | 人體安全性、倫理審查、臨床終點 | 永生、未驗證治療或醫療建議 |
| 跨物種福祉 | 可能受苦能力、來源細胞、動物衍生成分與危害評估 | 一切生物絕無苦難 |
| 生態延續 | 生命週期分析、時間序列、可信測量 | 無證據的環境永續成就 |
| 全球和平 | 衝突／死亡／正義指標、明確期間與地理範圍 | 世界和平已實現 |
| SDGs | 目標指標 ID、官方統計、基準年與區域 | 17 項 SDGs 已達標 |
| 培養肉 | 細胞來源倫理、食品安全、法規、LCA | 成品安全核准或必然免除苦難 |
| 心理社會 | 知情同意、可測量心理與社會結果 | 普世心理健康或文化效益 |
| 哲學與形上學 | 精確形式公設與有界證明、實證／象徵區別 | 推導神學本體論真理 |
| Trader_42 | 費用、滑價、樣本外資料、KILL、持倉和對帳 | 實盤下單、報酬保證、放寬原風控 |

現有 G13 文獻與 SDG／培養肉資料多是**來源範圍的元資料**，並非本程式已讀取的真實測量。G14 仍保留其原有 10 USDT 單筆、50 USDT 總曝險、0.001 BTC 曝險、30 秒冷卻與 1% 每日資產跌幅等預設風控；G24S 不會修改這些限制。實際配置仍可能另受原系統設定影響，原型不接觸交易所。

## 3. 合成樣本的重現結果

範例固定 12 個域，每個輸入為 `[synthetic_checks, veto]`。`synthetic_checks` 是**測試資料中人工指定的檢查個數**，不是外部量測成果，也不是 AI 或健康的真實指標。

| 類別 | 數量 |
|---|---:|
| 登錄領域 | 12 |
| 通過合成審查 | 5 |
| 資料不足 | 4 |
| 安全否決 | 3 |
| 精確質數冪數值更新 | 20 |
| 狀態登錄整數 | 98 bits |
| 完整組態整數 | 122 bits |
| 對外 API、交易與部署 | **0** |
| 經證明真實世界目標 | **0** |

明文 One-Liner：**1,991 UTF-8 bytes／一個實體行**。目前有 **126 項本機正反測試**，再以第二套不匯入主核心的審查器重算質數與除法，檢查整數和 One-Liner 報表是否一致。參考檔案：

- `deployment/Universal_G_G24S_Cross_Domain_2KB.sh`：唯一使用標準輸入 JSON 的 2 KB 單行原型。
- `deployment/G24S_cross_domain_core.py`：可讀且有嚴格輸入型別驗證的參考核心。
- `deployment/G24S_oneliner_builder.py`：從可閱讀模板重建明文原始碼。
- `deployment/G24S_independent_audit.py`：獨立數值及輸出審查器。
- `deployment/G24S_policy_core.py`：在 **TM-000 根目錄**唯讀核對 G13、G14、G23 父契約、風控與 180 天審查期限；過期一律拒絕，不作正式授權。
- `deployment/G24S_cross_domain_contract.json`：12 個領域的證據缺口及禁止推論。
- `deployment/G24S_example_request.json`：全合成測試輸入。
- `tools/test_universal_g_g24s.py`：126 項自動測試。

## 4. 執行與治理

在 TM-000 根目錄：

```bash
bash deployment/Universal_G_G24S_Cross_Domain_2KB.sh < deployment/G24S_example_request.json
python3 deployment/G24S_cross_domain_core.py < deployment/G24S_example_request.json
python3 deployment/G24S_independent_audit.py
python3 tools/test_universal_g_g24s.py
python3 deployment/G24S_policy_core.py --as-of 2026-11-10
```

禁止輸入具有 `network=true`、`deployment=true`、`trading=true`、`credentials=true`、`external_action=true` 的請求；未取得人類審查許可、任何非合成來源、少一個領域、偽造成功宣稱或格式不正確，都必須 fail-closed。這個模型**不能**在執行時向任何服務上傳資料、交易、部署、操作細胞培養設備、提供臨床治療或改寫正式總圖靈機。

## 5. 形式化界線

G24S 是 **12 個研究領域的有限質數冪治理登錄機**；不是 G23 的原生圖靈機編譯器，不證明此特定有限狀態機本身是通用圖靈機，也沒有與 G23 的 350 萬步模擬互相取代。質數冪的基本算術規則可以跨領域共用，**領域語意、證據與倫理規則不可藉共用算術互相替代**。真正可用的全自動部署需要另外的明確授權、資安隔離、平台側回滾設計與真人審核，不能從 `C` 的某個指數推導出實盤權限。

原始 TM-015、歷史 G23、正式總機 `UTM-PLEIADES-v0.2-PTCA` 及 Trader_42 皆保持不變。G24S 僅屬尚未合併的 GitHub 草稿 PR #20 研究成果。
