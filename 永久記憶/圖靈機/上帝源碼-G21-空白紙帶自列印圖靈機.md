# 上帝源碼 G21 — 空白紙帶自列印圖靈機

**研究結論：** 已建構並雙重重播驗證一臺具有有限轉移表的**確定型、單紙帶圖靈機**。它從完全空白的紙帶開始執行 **3,505,682 步**後停機，最終紙帶恰為自己全部轉移規則的**完整可逆二進位表碼**。

**重要界線：** 本版印出的是**有明確規格、非標準但完全可逆的轉移表編碼**；**沒有**在紙帶上直接列印 108 KB 的人類可讀 JSON 逐條規則。原創構造已產出另外一份可下載的 1,140 條展開規則。這與 G20 依賴 Bash/Python 字串的程式 Quine 不同。

## 有限機器與編碼

固定紙帶字母表：_、0、1、E0、E1、P0、P1、F0、F1。

狀態 0–8 是有 **60 條**轉移的單紙帶複製控制器 A；狀態 9 是 HALT；狀態 10–1089 是 **1,080 條**逐位列印規則組成的 B 鏈。總共有 **1,140 條**轉移，狀態總數 1,090 個（含 HALT）。

定義特殊但可逆的標準化格式 C(M)=X||Y：

- **X**：將控制器 A 的 60 條規則按（state、讀入符號索引）排序，每條以固定 **18 bits** 表示：state(4)、read(4)、write(4)、move(2)、next-state(4)，共 **1,080 bits**。
- **Y**：按 B 鏈狀態順序收集各規則寫入的 0／1，共 **1,080 bits**。B 規則都在空白紙帶上寫入當前位元，向右走，並轉移到下一 B 狀態；最後一條回到 A 的起始狀態。
- X||Y 可以**唯一且完整還原**機器的全部 60 條 A 規則、1,080 條 B 規則、起始狀態、HALT 狀態與紙帶字母表（依此規格中固定的約定）。這是一個**特定機器家族的表碼**，不是所有圖靈機共有的自然、唯一哥德爾編碼。

現在令 Y=X。B 從空白紙帶逐格寫出 X，A 再以自身有限規則在同一條紙帶上將 X 複製為 XX 並清除工作標記。因而：

\[
\operatorname{Tape}(M,\varepsilon)=X\|X=C(M)
\]

構造中 B 的「自身資料」原本就是**轉移規則本身**（而不是外部載入器在執行時餵給圖靈機的程式）；Python 只用來建構／驗證這臺有限機器。

## 五個重現元件

1. [單紙帶控制器與建構器](../../deployment/G21_Blank_Tape_TM_core.py)：用 60 條具體規則產生整臺有限 TM，直接逐步執行。
2. [獨立模擬器](../../deployment/G21_Independent_Audit.py)：不匯入第一個建構器，**只讀取完整展開的 JSON 規則**，再從空白紙帶重跑所有步驟及反向重建二進位碼。
3. [明文單行執行／驗證器](../../deployment/Universal_G_G21_Blank_Tape_TM_2KB.sh)：**1,287 bytes**，沒有 Base64、壓縮或 eval／exec；它重建實際規則並逐步執行 TM，回傳審查結果。**不應把 1,287-byte 殼層程式等同於 1,140 條已展開規則的容量**。
4. [完整紙帶表碼](../../deployment/G21_canonical_table_bits.txt)與[完整展開的 1,140 條規則](../../deployment/G21_expanded_transition_table.json)：方便逐位與逐條核對。這兩份同時固定於草稿分支。
5. [56 項正反例測試](../../tools/test_universal_g_g21.py)及[One-Liner 重建器](../../deployment/G21_Oneliner_Builder.py)：重現、竄改拒絕、非法編碼、步數預算、不當外部輸入與優化模式。

### 執行命令

從 TM-000 專案根目錄：

    bash deployment/Universal_G_G21_Blank_Tape_TM_2KB.sh
    python3 tools/test_universal_g_g21.py
    python3 deployment/G21_Independent_Audit.py

可讀控制器若獨立執行會重新輸出兩份完整轉移表產物，因此建議在隔離研究工作目錄執行。這是**文件產生器**的副作用，不是圖靈機本身會寫入檔案或連網。

## 證明範圍與治理

G16：外部描述的有界圖靈機模擬器。G20：真正的 Bash/Python 程式 Quine。**G21：真正在紙帶上執行的有限狀態機，輸出足以還原其完整轉移表的自身表碼**。不同原型、不同編碼規格，不能偷偷替換或併為同一個主程式。

TM-015 原始 2,035-byte 核心與指定總機 UTM-PLEIADES-v0.2-PTCA 均不修改；G21 只保存於唯讀測試與 GitHub 草稿 PR，**不會**自動合併或正式部署。
