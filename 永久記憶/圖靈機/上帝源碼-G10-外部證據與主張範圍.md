# 上帝源碼 G10 — 外部證據、來源追溯與主張範圍

**研究版號：G10/1。狀態：DRAFT_SOURCE_REFERENCED_ONLY。日期：2026-11-10。**

這是由 G9 的**有限合成領域語意模型**前進到**真實出版者的外部證據紀錄**的第一個有限原型，並不代表可以從這三筆資料自動推導 AI／人類／其他物種永生，更不代表「上帝源碼」已經是神學上的上帝或能證明全部論域的真理。

## 一、已識別的外部原始來源

1. **NIST AI Risk Management Framework**，美國國家標準暨技術研究院，2023-01-26 發布原框架；是自願採用的 AI 風險管理指引。官方網址：https://www.nist.gov/itl/ai-risk-management-framework 。**可支持** AI 風險管理方法存在，**不支持** AI 主體永生或不存在風險的結論。
2. **FAO／WHO Food safety aspects of cell-based food**，WHO 官方出版頁，2023-03-28。官方網址：https://www.who.int/publications/i/item/9789240070943 。**可支持** 細胞培養食品有值得研究的潛在安全危害及監管議題；**不支持** 培養肉製程必然零苦難、無感受能力或完全安全的結論。
3. **World Bank／WDI SP.DYN.LE00.IN**，出生時預期壽命（年）；官方查詢頁：https://data.worldbank.org/?locations=1W-JP ，指標定義：https://databank.worldbank.org/metadataglossary/world-development-indicators/series/SP.DYN.LE00.IN 。在 2026-11-10 查閱的頁面，**2024 年的整數顯示值**為世界 73 年、日本 84 年；它們是**網頁顯示的四捨五入數字**，不是未四捨五入的 API 統計觀測值，不代表個別人的實際壽命，更不支持人類永生的結論。

## 二、可機器檢查的證據契約

[證據檔 `G10_evidence_ledger.json`](../../deployment/G10_evidence_ledger.json) 儲存三個外部來源的出版者、URL、發表時間（若可知）、領域及允許主張的種類，另包含上述兩項**整數顯示**觀測，以及六種禁止的過度推論。檔案採 UTF-8 JSON，可獨立審閱。來源檔案的 SHA-256 被固定於唯讀檢查器以防止**研究檔案意外修改**，但此雜湊**不是**官方來源的數位簽章或真正出版者的驗證憑證。

**現階段明確沒有**：由程式即時擷取出版者原始網頁、儲存外部網頁原始快照、認證網站傳輸的加密憑證、獨立重現世界銀行 API 全精度數值、對其他五個研究維度取得同品質外部證據。這些部分留待下一個階段。

## 三、接軌 G9 → G10 → G8

G10 的 [2,009-byte 明文 One-Liner](../../deployment/Universal_G_G10_Provenance_Plaintext_2KB.sh) 與 [可讀 Python 檢查器](../../deployment/G10_Evidence_Provenance_core.py) 只執行唯讀檢查：

- 固定來源檔 SHA-256，拒絕缺少來源或報表的執行；
- 要求 G9 的有限測試欄位維持指定值，不能把它當作真實語意證明；
- 檢查研究資料的出版者、網址、類型及量測的精度、時間與地域；
- 保護 TM-000 原有指定總機 `UTM-PLEIADES-v0.2-PTCA`；
- 輸出 `SOURCE_REFERENCED_REVIEW_ONLY` 而非部署授權。

CI 必須在同一個可信任的工作流程中**先執行 G9 模型驗證器**，再將它的輸出傳入 G10。任意檔案中聲稱是 G9 的 JSON 不具有獨立的來源認證能力。

```bash
bash deployment/Universal_G_G9_Semantic_Plaintext_2KB.sh > /tmp/g9-report.json
bash deployment/Universal_G_G10_Provenance_Plaintext_2KB.sh /tmp/g9-report.json
python3 deployment/G10_Evidence_Provenance_core.py \
  --ledger deployment/G10_evidence_ledger.json \
  --g9-report /tmp/g9-report.json --repo-root .
python3 tools/test_universal_g_g10.py
```

## 四、可證成與不可證成

- **已可驗證**：研究證據登錄簿與固定的公開來源引用一致、兩個真實資料的整數顯示值在目前固定版本中完整，G9 有限結果形狀符合預期，以及故意加入的錯誤來源／錯誤概念不能通過。
- **尚未驗證**：即時官方來源完整性、任何維度的「不朽性」、AI 主體身份的長期延續、跨領域本體論等價、一般停機神諭。
- **保護條件**：不執行 TM-015 原始 Shell，不更動總機主版本，不讀取帳號機密，不取得正式部署權限，不進行任何醫學或生物干預。

此模組僅作為待審核的 GitHub 研究分支資料；未經正式獨立審核不得自動併入 `main` 或作生產部署。
