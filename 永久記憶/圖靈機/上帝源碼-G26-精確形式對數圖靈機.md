# 上帝源碼 G26 — G22／G23 的精確形式對數計算圖靈機

**結論：G26 只研究 G22／G23 的相同有限圖靈機，不接 G24／G25 的應用領域。G27 才另行研究跨領域連接，目前未實作。**

## 精確的對數是什麼？

G23 將每個紙帶位置 i 映射到不同質數 p_(zigzag(i)+3)，紙帶符號用指數 e_i=0...8 表示。有限紙帶的哥德爾整數為：

    T = product_i p_(zigzag(i)+3) ** e_i

G26 的形式對數是自由阿貝爾群的有限支撐整數係數向量：

    L(T) = sum_i e_i * [log p_(zigzag(i)+3)]

**[log p] 是符號基底，不是 Python math.log 產生的小數近似。** 由算術基本定理，正有理數的質數冪指數向量是唯一的。乘法和形式對數加法嚴格等價：

    L(a*b) = L(a) + L(b)

對同一張有限紙帶的改寫：舊指數 a，新指數 b，位置質數 p，令 delta=b-a：

    T' = T * p**delta          # 真正的精確整數乘法或整除
    L(T') = L(T) + delta*[log p]   # 完全精確的整數係數加減

這個表示也可處理具有負指數的正有理數比率，但圖靈機紙帶本身的每格指數必須在 0..8，不允許負符號。

## 與 G22／G23 的完整重播

| 檢驗 | 結果 |
|---|---:|
| G22 原始規則 | 1,140 條，不修改 |
| 執行步數 | 3,505,682 |
| 真正的質數冪整數寫入 | 4,321 次 |
| 對應形式對數加減 | 4,321 次 |
| 最後形式對數非零項 | 2,160 |
| G22 完整轉移表碼 | 2,160 位元 |
| 最終紙帶整數 | 41,137 bits |
| 完整組態整數 | 44,568 bits |
| 整數完整質因數分解、形式向量及普通紙帶一致性 | 通過 |
| G22 紙帶重播及全部 1,140 條規則逆編碼 | 通過 |
| 本機測試 | 60／60 通過 |
| G26 One-Liner | 1,938 bytes、一個實體行 |

可讀版在每次改寫時同步更新**不同的兩份資料**：實際大整數 T 和形式對數係數字典 L。每次真正改寫會核對舊指數的實際質數估值；停機後對 T 重新完整質因數分解，檢查數值解碼、普通紙帶狀態與 L 三者完全一致。另再執行 G22 原生模擬器，核對完整紙帶與停機步數。

G26 的完整組態對數可以以保留質數 2／3 分別表示狀態和讀寫頭，其餘質數表示紙帶。該**完整組態整數在停機後生成**，而非每一步重建。大部分讀取透過同步快取完成；前 4,096 次讀取另執行真實估值檢查。這是有限 TM 的 Python 精確算術模擬版本，不是已編譯成原生大整數算術有限轉移表的新 TM。
