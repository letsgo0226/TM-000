# 上帝源碼 G5 — 跨論域自然性定理（Universal G Natural-Point Theorem）

**狀態**：可形式證明的數學子命題；有限測試原型已通過。**不等同於已證明 G 是神學上的上帝，也不等於在所有不受限制的論域中都存在同一個對象。**

## 1. 論域與形態

令 **Mon** 為（在適當集合論基礎或固定 Grothendieck 宇宙中）幺半群及保持乘法與單位元素的同態所形成的範疇。令 \(U:\mathbf{Mon}\to\mathbf{Set}\) 是忘卻函子，令 \(\Delta 1\) 為值恆等於單元素集合的常值函子。研究自然變換 \(G:\Delta1\Rightarrow U\)，也就是一個選擇規則：每個幺半群 \(M\) 選出 \(G_M\in M\)，對任何同態 \(f:M\to N\)，滿足 \(f(G_M)=G_N\)。

## 2. 定理（存在與唯一性）

\[
\boxed{\exists!\,G:\Delta1\Rightarrow U,\qquad G_M=e_M\quad(\forall M\in\mathbf{Mon})}
\]

**存在性**：令 \(G_M=e_M\)。依幺半群同態的定義，\(f(e_M)=e_N\)，故形成自然變換。

**唯一性**：令 \(I=\{e_I\}\) 是平凡幺半群。對任意幺半群 \(M\)，有唯一同態 \(u_M:I\to M\)，且 \(u_M(e_I)=e_M\)。假設 \(H:\Delta1\Rightarrow U\) 為任一自然變換。因為 \(I\) 只有一個元素，\(H_I=e_I\)。由自然性 \(H_M=u_M(H_I)=e_M\)。因此 \(H=G\)。證畢。

此唯一性是**自然選取規則的唯一性**，而不是「所有幺半群的元素都是同一個東西」。它涵蓋字串串接、整數加法、整數乘法、集合聯集及函數合成等例子，各自的 \(e_M\) 並不相同。

## 3. 反例（不能不加限制地推廣）

對所有非空集合與雙射，想要自然地為每個集合 \(X\) 選擇 \(g_X\in X\)，必須在任意自同構 \(\sigma:X\to X\) 下滿足 \(\sigma(g_X)=g_X\)。然而 \(X=\{0,1\}\) 的交換雙射 \(\sigma(0)=1,\sigma(1)=0\) 沒有不動點。故此種普遍自然選擇**不存在**。

因此「不限論域」若解釋為不加任何結構與映射限制的一切對象，不能由本定理推得。只有明確指定的論域範疇及結構保持映射，才能形成可檢驗的普遍性。

## 4. 與 G、Gödel、God 的關係

- \(G_{\mathrm{identity}}=E_P(\varepsilon)=1\) 只用於字串幺半群的空字串，\(\varepsilon\) 的質數位元組編碼採初值 1。其他幺半群的單位元素通常不是這個整數。
- \(G_{\mathrm{code}}=E_P(Q)\) 是某份固定程式 \(Q\) 的有限可逆編碼；與前述自然變換不是同一型別的數學對象。
- \(G_{\mathrm{God}}\) 是與上帝概念關聯的**本體論／神學詮釋假說**。將上述自然性定理當成詮釋素材可以，但該定理不證明神存在、神具備特定屬性、圖靈機等同神、全域停機判定或主觀永生。

## 5. 可執行的有限模型驗證

`deployment/Universal_G_Naturality_2KB.sh`（1,107 bytes）建立七個有限幺半群（含平凡幺半群），逐項測試封閉性、結合律、雙側單位元素唯一性，並窮舉其中 **116** 個幺半群同態，確認都保留單位元素。也驗證兩點集合交換映射沒有不動點。

```bash
bash deployment/Universal_G_Naturality_2KB.sh
```

這些測試是對數學證明的**有限實作例證**，不是以有限枚舉證明無限範疇的定理。範疇普遍性依據第 2 節的演繹證明成立。
