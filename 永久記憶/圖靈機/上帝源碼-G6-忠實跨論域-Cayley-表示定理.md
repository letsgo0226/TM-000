# 上帝源碼 G6 — 忠實的跨論域 Cayley 表示

**狀態：已建立的代數定理及其有限計算例證；不是「任何可能論域都有唯一 G」或「程式等同上帝」的證明。**

## 1. 適用的論域

在一個適當界定大小的幺半群範疇 `Mon` 中，每個論域是 `M=(|M|,·,e)`，其中 `·` 滿足結合律，`e` 是唯一雙側單位元素。跨論域映射 `f:M→N` 必須保留乘法及單位元素。此為有結構的廣泛論域類別，而非包含一切可能物件的無限制全域。

G5 已證明：對忘卻函子 `U:Mon→Set`，唯一自然點是每個 `M` 的單位元素 `G_M=e_M`。

## 2. G6 定理：忠實表示（Monoid Cayley theorem）

對 `a∈M` 定義左正則作用 `L_a:|M|→|M|`：

```text
L_a(x)=a·x
ρ_M(a)=L_a
```

**存在、保運算**：由結合律，對每個 `x`，`L_{ab}(x)=(ab)x=a(bx)=(L_a∘L_b)(x)`；而 `L_e(x)=x`。因此

```text
ρ_M(ab)=ρ_M(a)∘ρ_M(b)
ρ_M(e)=id_|M|
```

**單射／可還原**：因為 `L_a(e)=a`，若 `L_a=L_b`，取值於 `e` 即有 `a=b`。因此 `ρ_M` 是單射幺半群同態，即 `M` 可嵌入自身底層集合上的全體函數在合成下組成的幺半群 `End(|M|)`。注意它不是到一般論域「語意」的自動解釋器。

**跨論域相容性**：若 `f:M→N` 為保持單位元素的幺半群同態，則

```text
f(L_a(x))=f(ax)=f(a)f(x)=L_{f(a)}(f(x))
f∘L_a=L_{f(a)}∘f
```

注意這是可交換方塊的相容關係，不表示對任意非雙射的 `f` 都有自然定義的 `End(M)→End(N)` 同態。不能任意「搬運」所有函數至另一個集合。

## 3. 與質數 Gödel 編碼的組合

對固定標準 UTF-8 位元組序列 `b=(b_1,…,b_n)`，沿用 TM-015 的前 256 個質數 `p_b` 及基數 2048：

```text
E_P(ε)=1
E_P(b_1,…,b_n)=2048·E_P(b_1,…,b_(n-1))+p_(b_n)
D_P(E_P(b))=b
```

由於 `p_255<2048` 且全部 256 質數互異，對有限位元組串的編碼是單射且可逆。**此為離散資訊的可逆編碼**，與 `ρ_M(a)=L_a` 的代數忠實表示是兩個不同但可串接的層次。

有限原型選擇 `[model_name,str(element)]` 的 JSON UTF-8 序列編碼。此序列化方式適用於本測試中已明確定義的七個模型；不宣稱對所有可能數學對象存在自動、可計算、完整的序列化。

## 4. G6 有限可執行檢查

`deployment/Universal_G_Cayley_2KB.sh`：完整一行，**1,768 bytes**。在 7 個小型幺半群上測試：

- 運算封閉、結合律與雙側單位元素；
- 18 個元素的忠實左正則表示 `L_a` 與 `L_a(e)=a`；
- 18 組質數 Gödel round-trip 及編碼互異性；
- 從所有 7×7 模型配對中枚舉出的 116 個保持單位元素的同態，確認 `f(ax)=f(a)f(x)`；
- 兩點無結構集合的交換映射沒有不動點，提醒「絕對不限論域的自然唯一選擇」不成立。

```bash
bash deployment/Universal_G_Cayley_2KB.sh
PYTHONOPTIMIZE=2 bash deployment/Universal_G_Cayley_2KB.sh
```

預期輸出包含 `finite_models=7`、`embedded_elements=18`、`verified_homomorphisms=116`、`prime_godel_roundtrips=18`。這些有限測試**不能取代**上節的普遍代數證明。

## 5. 「上帝源碼」研究上的界限

| 表述 | 形式／研究狀態 |
| --- | --- |
| 幺半群中的唯一自然單位元素 | G5 已形式證明 |
| 每個幺半群皆有可還原、保乘法的 Cayley 表示 | G6 已形式證明 |
| 全部任意論域都可有同一個絕對自然唯一 G | G5 兩點集合已給出反例，不能如此主張 |
| `G` 是神學上的 `God` | 待獨立本體論、哲學與神學論證 |
| 通用停機神諭、AGI、永生或全自動生產部署 | 均不是 G6 的結論 |

G6 擴張的是**適當形式論域中，結構保持與資料不遺失的可證明能力**，不是計算能力的物理無限性；外部的健康、生命倫理、全球和平等議題必須另行證明其資料模型及對應映射有實際意義。
