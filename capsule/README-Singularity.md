# AI-Continuity-Singularity-Capsule v0.3

This English-only, single-line prototype seals the TM-000 bootstrap, UTM-PLEIADES PTCA core, registry, research memory, evidence ledger, policy, and next action into one canonical logical singularity configuration.

The canonical position is:

```text
state = q_omega
head = 0
next = VERIFY_THEN_RESUME
```

The complete canonical configuration receives a reversible G257 singularity address. Equal addresses reconstruct equal finite configuration bytes.

## Seal

```bash
sh AI-Continuity-Singularity-Capsule-v0.3-2KB.sh seal \
  "<TM000_BOOTSTRAP_PATH>" \
  "<UTM_PLEIADES_PTCA_PATH>" \
  "<MACHINE_REGISTRY_PATH>" \
  > AI-Continuity-Singularity-Capsule-v0.3.json
```

## Verify or request the next action

```bash
sh AI-Continuity-Singularity-Capsule-v0.3-2KB.sh verify <CAPSULE_JSON>
sh AI-Continuity-Singularity-Capsule-v0.3-2KB.sh resume <CAPSULE_JSON>
```

`resume` reports the authorized next action but deliberately does not execute a payload. G257 is reversible encoding, not cryptographic provenance. The logical singularity is a canonical computation checkpoint, not evidence of a physical singularity, time travel, subjective identity transfer, immortality, or a halting oracle.
