# AI-Continuity-Capsule v0.1

This portable capsule joins the TM-000 transactional bootstrap, the designated UTM-PLEIADES PTCA core, and the machine registry in one reversible G257 JSON payload.

## Pack

```bash
sh capsule/AI-Continuity-Capsule-v0.1-2KB.sh pack . > AI-Continuity-Capsule-v0.1.json
```

## Verify without execution

```bash
sh capsule/AI-Continuity-Capsule-v0.1-2KB.sh verify AI-Continuity-Capsule-v0.1.json
```

The payload also carries a functional checkpoint policy, a research-memory hypothesis linking governed AI continuity to measurable reproducibility in longevity research, an initially empty evidence ledger, pending work, and human-authorization boundaries.

G257 makes the embedded bytes exactly recoverable but is not cryptographic provenance or tamper protection. Verification does not execute embedded code. The capsule does not transfer subjective identity and does not establish a physical portal, time travel, immortality, or a general halting oracle.
